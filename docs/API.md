# API Reference

Base URL (local dev): `http://localhost:8000`. Interactive docs at `/docs`
(Swagger UI, auto-generated by FastAPI) once the server is running.

## Profile

| Method | Path | Description |
|---|---|---|
| GET | `/api/profile/{learner_id}` | Fetch (or lazily create) a learner profile. |
| PUT | `/api/profile/{learner_id}` | Update profile fields (name, goal, skill_level, interests, completed_courses, hours_per_week, preferred_format). |

## Chat

| Method | Path | Description |
|---|---|---|
| POST | `/api/chat` | Body: `{learner_id, message}`. Extracts profile fields from free text and returns an assistant reply. |

## Recommendations

| Method | Path | Description |
|---|---|---|
| GET | `/api/recommend/{learner_id}?limit=5` | Ranked course recommendations with a `reason` per item. |
| POST | `/api/recommend/{learner_id}/explain` | Body: `{learner_id, course_id}`. Returns a natural-language explanation for one course. |
| POST | `/api/recommend/{learner_id}/ask` | Body: `{learner_id, question}`. Free-form Q&A grounded in the learner's current recommendations. |

## Learning Path

| Method | Path | Description |
|---|---|---|
| POST | `/api/path/{learner_id}/generate` | (Re)generates a milestone-based roadmap from the learner's current profile. |
| GET | `/api/path/{learner_id}` | Fetch the stored path (404 if none generated yet). |

## Progress

| Method | Path | Description |
|---|---|---|
| PUT | `/api/progress/{learner_id}` | Body: `{learner_id, milestone_id, status}`. status is one of `not_started`/`in_progress`/`completed`. |
| GET | `/api/progress/{learner_id}` | Dashboard snapshot: completion %, skill growth, next actions. |

## Misc

| Method | Path | Description |
|---|---|---|
| GET | `/` | Service info. |
| GET | `/healthz` | Health check. |
